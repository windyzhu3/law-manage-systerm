# V0.16 Todo Engine 第一阶段验收报告

## 验收结论

V0.16 从远程 `v0.15` 的 `f3214c1c6349539562d68c9d7f9bb79339c35d05` 建立，采用模块化单体新增独立 `law-todo` 模块。第一阶段设计范围已实现，并由本地全量构建和 GitHub Actions 的后端、前端、MySQL/Flyway 三类质量门禁验证。

## API 验收

- `GET /todo/dashboard|list|{id}`
- `POST /todo/{id}/claim|start|submit|complete|return|transfer|cancel`
- `POST /todo/{id}/attachment|candidate|cc`
- `GET|POST|PUT /todo/template`
- `GET|POST /todo/template/trigger`
- `POST /todo/template/{id}/publish`
- `GET|POST|PUT /todo/calendar`
- `POST /todo/sla/scan|{id}/pause|{id}/resume`
- `GET /todo/notification`、`POST /todo/notification/{id}/read`

所有写接口使用强类型 DTO；生命周期动作要求非空 `actionId`；业务异常返回稳定 `businessCode`。

## 自动化验证

本地验证命令：

```text
mvn --batch-mode --no-transfer-progress -DskipTests=false clean package
npm run test:todo
```

本地 Maven Reactor 九个模块全部 `SUCCESS`，Todo Engine 覆盖状态转换、访问策略、DoD、日历、SLA、模板、路由、事件、通知、协作和持久化契约测试。

GitHub Actions 质量门禁：

- 后端：`mvn clean verify`；
- 前端：安装依赖、Todo UI 契约、`npm run build:prod`；
- 数据库：从空 MySQL 8 初始化 v0.15 基线，真实 Flyway 执行并断言当前版本为 `0.16.5`。

首轮完整门禁运行：[GitHub Actions #29187709876](https://github.com/windyzhu3/law-manage-systerm/actions/runs/29187709876)，三个任务全部成功。

## 阶段边界

阶段一不包含可视化流程设计器、复杂表达式 DSL、MQ、微服务、多租户、移动端或全业务链路接入；这些不属于本次验收范围。V0.16 已为后续合同、案件、财务等业务事件接入提供统一模板、事件、DoD、SLA、权限和审计能力。
