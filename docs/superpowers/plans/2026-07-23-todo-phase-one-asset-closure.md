# Todo Engine 阶段一业务资产闭环实施计划

> 目标：在保持发布版本不可变的前提下，补齐 v0.2 标准模板所需的 SLA、DoD、负责人解析、批量模拟和发布前诊断，达到阶段一验收标准。

## 任务 1：固化验收契约

- 扩展 Flyway 真实数据库测试，先声明默认规则数量、标准模板最新版本绑定、旧版本退役、触发规则指向和负责人字段一致性。
- 增加批量模拟服务测试，覆盖成功、负责人无法解析、资源缺失和草稿未通过预检。
- 先运行相关测试并确认失败，再进入实现。

## 任务 2：补齐默认 SLA/DoD 业务资产

- 新增 `V0_20_40` 前向迁移，创建语义化 SLA 与 DoD 规则。
- 为 15 个已发布主链路标准模板生成新的已发布版本，规则以快照固化，并登记规则来源引用。
- 将同一模板的历史发布版本转为 `RETIRED`，让运行时和管理界面只有一个当前发布版本。
- 修复 `LEAD_FIRST_CONTACT` 使用不存在的 `toOwnerId`，统一为事件目录中的 `ownerId`。
- 更新触发规则指向新版本，并保持事件、业务类型和模板一致。

## 任务 3：建立发布版本批量模拟与缺口清单

- 后端提供“最新发布版本批量诊断”能力，使用事件目录样例和可选真实对象生成模拟请求。
- 结果按模板返回负责人、SLA、DoD、路由、资源及错误码，不因单个失败中断整批。
- 页面增加批量诊断入口、汇总卡和可定位修复的失败列表。

## 任务 4：改善草稿预检反馈

- 模板列表直接显示发布阻断数和最近预检状态。
- 打开草稿时展示字段级问题、规则绑定缺失和对应配置入口。
- 发布按钮在阻断时给出结构化问题面板，不再只显示通用提示。

## 任务 5：全量准入验证

- 运行 `law-todo` 全量测试、前端契约测试、前端生产构建和全 Maven 打包。
- 从 v0.15 基线创建全新 MySQL 数据库，执行至最新 Flyway 并验证资产与绑定。
- 启动前后端，用浏览器完成资源中心、模板编辑、规则绑定、单次/批量模拟和发布前诊断验收。
- 更新阶段一验收报告，只在全部 P0 条件有证据时声明可进入阶段二。
